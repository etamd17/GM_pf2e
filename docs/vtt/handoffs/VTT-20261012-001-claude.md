  - React owns the surrounding interface; a plain-TypeScript SceneRuntime owns Pixi through one host element. No @pixi/react.
  - 11 fixed map layers with event-driven, render-on-demand updates and two-level cache keys.

  - Keyboard and screen-reader access, reduced motion, and WebGL context-loss recovery are designed in.
  - 13 multi-client Playwright scenarios assert on raw socket frames as well as on what is rendered.
