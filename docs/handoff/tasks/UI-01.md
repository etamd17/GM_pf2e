## Goal
Get a user-approved direction for each remaining Cosmere screen: generators, character sheet,
level-up, builder.

## How the mockups are made
`docs/handoff/assets/UI-01-review/` (local only, gitignored). `build.py` takes the real page as
rendered by the app (`current-raw.html`, captured with a throwaway campaign) plus real generator
outputs (`pool.json`), and writes `current.html`, `a.html`, `b.html` and a comparison
`index.html` into a `site/` folder with a copy of `static/`. Serve that folder with any static
server (`python -m http.server`). Rerolls use the captured outputs; every other network call is
blocked; links are disabled.

## Decisions

| Screen | Decision |
|---|---|
| Cosmere generators | **A: Labelled** (2026-10-13). Same grid; text buttons Back / Copy / Pin / Roll 5 / Reroll; flatter cards; a one-line explanation that Reroll all skips pinned cards; bigger tap targets on phones. Matches the approved PF2e generators. B (grouped sections + filter + pinned strip) was not chosen. |
| Cosmere character sheet | **A: Play-first + tabs** (2026-10-13). One top band with Health/Focus/Investiture rings, the defenses and the six attributes; conditions, rest buttons and move/senses in a strip under it; then tabs **Play** (skills, roll tools, strikes, actions) / **Radiant** (only when the character has it) / **Gear** (inventory, spheres, fabrials) / **Character** (talents, expertises, goals, notes). On phones the three rings fit one row. B (two columns, sticky left vitals) was not chosen. |
| Cosmere builder + level-up (one page: the builder in edit mode) | **B: Level-up guide** (2026-10-13). A's tidier chrome (slim draft bar replacing the unstyled box, intro folded into the help box, step row and preview panel stay in view) plus a **Still to choose** list at the top of the preview panel built from the engine's own budgets (attribute points, skill ranks, expertises, talents; each with a Go button to its step), "N left" badges on the step row, and a "Leveling up: 5 -> 6" badge when the level is raised. |

## Checks done (generators)
- Control inventory identical in current / A / B: 9 rerolls, 9 pins, 9 backs, 9 copies,
  2 "roll 5", Reroll all, Copy all (`build.py` prints it).
- Pin, back-history and reroll work in the preview; Mistborn skin switches; phone width 375px has
  no sideways scroll; buttons 32px tall on phones.

## Checks done (sheet)
- Sample: a level 5 Windrunner warrior with no rule warnings (`capture_sheet.py`), damaged, Exhausted.
- The mockups MOVE the real sections into the new layout (`sheet_layout.js`), never recreate them:
  61 click handlers and 123 ids identical in current / A / B.
- Phone (375px): no sideways scroll in current, A or B. Headless-Chrome screenshots at 390px look
  cut off because headless Chrome has a minimum window width; check phones in a real viewport.
- Implementation note for UI-02: the sheet keeps a mobile vitals bar (`#cs-vbar`); decide whether
  A's band replaces it on phones or it stays for scrolled-down tabs.

## Checks done (builder)
- The live preview panel was answered by the app's real `/cosmere/builder/preview` (read-only) through
  `serve.py`, so its numbers are the engine's, not invented.
- Same character, edit mode: 108 click handlers / 154 ids in current, A and B.
- Raising level 5 -> 6 in B: the list grew by 1 attribute point, 2 skill ranks, 2 talents; Go jumps
  to the right step; the badge appears.
- Implementation notes for UI-02: (1) the step row's existing check marks can sit beside "1 left"
  (e.g. Skills shows a check with 4 ranks unspent) -- show the check only when nothing is left;
  (2) the draft bar is `_character_draft_controls.html`, shared with the PF2e builder and import
  pages, so restyle it once for all of them; (3) expertises are on the Skills step, talents on Heroic
  Path.
