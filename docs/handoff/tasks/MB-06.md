- **Owner:** codex (standard model, high effort). Claude reviews the findings and any fixes,
  and repeats a sample in the browser.
- **Branch:** `codex/mb-06-mistborn-browser-pass` from current `origin/main` (after PR #225).

  type; the GM decides it at the table.**

## Part 1: record the knife ruling (private bundle only)

1. Move `mistborn.adversary.outlaw-boss.action.knife` from still blocked to verified. Its
   automation must say the GM adjudicates the Afflicted damage type. **Do not add a damage type.**
   Cite the source page (WG 259 / PDF 262) plus "user ruling 2026-10-26" as the reason.
2. Do it through the bundle's own authoring and review path, bumping only the package that holds
   the record (a new reviewed release, e.g. 1.1.2). Old versions and pins must keep loading, as
   they did in MB-02, and `validate_source_review` must still pass with the ledger at 0 still
   blocked.
3. If the review tooling cannot record a user ruling without weakening its checks, **stop and
   report**. Don't loosen the validator to make it fit.
4. Produce one archive that carries every version, so the user installs once. Report its SHA,
   the expected version count and the registry hash, and update the install steps in `MB-02.md`.
   Rules data stays out of git.

## Part 2: the browser pass

Seed a throwaway local `DATA_DIR` with a local test GM, a player account, and one campaign each
for **Mistborn Era 1**, **Mistborn Era 2** and **Stormlight** (control). Each Mistborn campaign
needs at least two characters: one Allomancer (or Misting), and one Feruchemist (or Ferring).
Then check every screen below on **desktop and phone width**, as the GM and, where it applies,
as the player:

| Screen | Look for |
|---|---|
| `/cosmere/builder` (+ preview) | Era-correct options; Allomancy/Feruchemy choices save and reload; no Roshar paths, Ideals or Surges |
| `/cosmere/pc/<pid>`, `/cosmere/sheet/<actor_id>` | Investiture, metals, boxings/clips wallet, rest, notes, live repaint when the GM changes state from another tab |
| `/cosmere/pcs`, `/cosmere/player` | Roster and player home use Scadrial wording; links work |
| `/cosmere/bestiary` | Reviewed adversaries show up per era. Spot-check the MB-02 fixes: the Mistborn Assassin and Steel Inquisitor have one combined Burn Iron/Steel and Ironpull/Steelpush; the Ironeyes burn-atium appears in both eras; the Outlaw Boss knife shows the type as GM-decided |
| `/cosmere/combat`, `/cosmere/gm`, `/cosmere/gm/vitals`, `/cosmere/gmscreen` | Adding Mistborn adversaries and PCs, turn order, conditions (including Afflicted with no type), Investiture and focus changes |
| `/cosmere/generator`, `/cosmere/loot` | Era-correct generator output; loot awards in boxings/clips with exact reversal |
| `/cosmere/homebrew` | Create, edit and delete under Mistborn; it stays in this campaign |
| Navigation, tooltips, page titles | No Roshar wording anywhere under the Mistborn skin (the MB-05 kind of bleed) |
| Stormlight control | The same screens look and behave as before |

Also watch the browser console and server log on every screen. Any error counts as a finding.

## What to fix and what to report

- **Fix in this branch:** wording and skin bleed, broken links or buttons, layout breaks at
  phone width, console errors. Each fix needs a focused test. Stormlight output must stay
  identical.
- **Report only, as proposed new MB tasks:** anything that would change rules data, engine
  behaviour, saved character or wallet formats, or needs a design decision. Give the steps to
  reproduce and say which era.

## Accept

- **A findings table:** screen, era, desktop/phone, GM/player, what is wrong, severity
  (blocker/major/minor), and whether it was fixed here or proposed. Include a short "checked,
  fine" list so the coverage is visible.
- **Part 1:** the archive installs locally from a clean `DATA_DIR`, keeps every old version,
  and `test_mistborn_review.py` passes against it with no skips.
- The focused tests, the full Cosmere suite and `python tools/check_templates.py` pass, with
  real numbers.
- **Nothing private in git:** no book text, bundle content, or screenshots that show bundle
  text. Keep screenshots under the gitignored `.superpowers/`.
