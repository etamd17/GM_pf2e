## Goal

Every one of the 252 records ends in exactly one state, with a reason:
- **verified:** it matches the source;
- **corrected and verified:** wrong in the bundle, fixed in the private bundle, rechecked;
- **removed:** not in the source, or not something the app should hold;
- **still blocked:** cannot be decided without the user, with the specific question.

## Approach

1. Reproduce the blocking list and its count from the tooling before changing anything. If the
   count is not 252, report the real number and why.
2. Check records in groups (by package, then by kind). For each one, record the source location
   (book and page or section, never the text) and the outcome.
3. Make corrections only in the private bundle, through the bundle's own build or installer path,
   so validation and versioning still apply. Bump the package versions you change, so installed
   sites can tell.
4. **Don't change rules engine behaviour to make records pass.** If the engine misreads a correct
   record, report it as a separate finding.
5. Rerun the validator and the full Cosmere suite, and confirm Stormlight is unaffected.

## Accept

- A table in the report: record id, package, outcome and source location. Counts per outcome add
  up to the reproduced total.
- The rebuilt private bundle installs and validates locally. The steps to install it on Railway
  are written down; installing it there is the user's step.
- The full Cosmere suite passes and all templates parse.
- No book text or bundle content anywhere in git.
