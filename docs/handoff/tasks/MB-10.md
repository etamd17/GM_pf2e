## Report (Claude, 2026-10-28)

1. **Draft labels.** The landing list read only `form.name` or `form.build.name`. Both Cosmere
   builders keep form fields in `form.fields` and the name in `submission.build.name`, so their
   drafts (Stormlight's too) were unnamed. New `_workflow_draft_label(inputs)` reads the submission,
   then the form, and falls back to "Untitled character" for a blank or non-string name.
   - Test: `tests/character_workflows/test_draft_label.py`.
2. **The post-publish redirect.** In `static/js/character_drafts.js`, a successful publish left
   `publishAttempt` set. `onPublished` then calls `location.assign(...)`, which fired the
   `beforeunload` guard. A normal browser shows a "Leave site?" dialog right after publishing; the
   embedded browser blocks the navigation outright.
   - **Fix:** on an acknowledged publish, clear `publishAttempt`, mark committed and `destroy()`
     (removing the guard) before `onPublished`. A failed or uncertain publish is unchanged: it keeps
     its attempt and its guard.
   - Test: `test_draft_controller.py::test_successful_publication_releases_the_leave_page_guard`.
   - This affects every builder that uses drafts (PF2e and both Cosmere builders), only on the
     success path.
3. **Metalmind charges.** Each idle metalmind card has a Charges box (1 to the metalmind's
   maximum), and Store/Tap read it instead of `prompt()`. Out-of-range values are refused with a
   message, and nothing is sent.
   - Test: `test_mistborn_pages.py::test_store_uses_the_cards_charges_box_not_a_browser_prompt` runs
     the sheet's real `mbAction` under Node with a stubbed card and fetch. A stubbed `prompt()`
     throws if it is called.
