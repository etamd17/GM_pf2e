  its parent element, and safely ignore targets without an applicable element. Preserve
  ordinary element clicks, keyboard behavior and the existing pill interaction.

### Required change

**The empty "Fabrials" heading still shows on an interactive Mistborn sheet.**

- **The cause:** the section renders on `{% if fabrials or crafted or interactive %}`, so with the
  Workshop gone, a Mistborn GM or owner with no fabrials sees an empty Roshar heading.
- **Also:** at 375 px it breaks mid-word ("FABRIAL / S").
- **The fix:** use `fabrials or crafted or (interactive and cosmere_world != 'mistborn')`, so a
  Mistborn character that somehow holds fabrials still shows them, and add a test.
